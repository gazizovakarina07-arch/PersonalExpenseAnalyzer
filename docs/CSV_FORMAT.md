# Формат CSV первой версии

Поддерживается самостоятельно подготовленная выписка установленного формата,
а не произвольный экспорт банка. Пример: `data/demo_statement.csv`.

```csv
date;description;amount;account
2026-10-01;Пятерочка;-650.00;Основная карта
2026-10-02;ИП Иванов;-120.00;Основная карта
```

- Кодировка UTF-8.
- Заголовок обязателен и должен точно совпадать с первой строкой примера.
- Четыре столбца в указанном порядке; разделитель — точка с запятой.
- `date`: существующая календарная дата `YYYY-MM-DD`, год 0001–9999.
- `description`: непустое описание продавца/операции.
- `amount`: рубли, обязательная точка и две цифры копеек. Перед числом допускается
  `-` или `+`; без знака число положительное. Ноль запрещён. Пробелы, запятая,
  разделители тысяч и экспоненциальная запись запрещены. Значение в копейках должно
  помещаться в int64_t: от -92233720368547758.08 до 92233720368547758.07 рубля.
- `account`: непустое название счёта. Валюта всех операций — рубль.
- Категории во входном файле нет. Импортёр оставляет её отсутствующей.
- Поля можно заключать в двойные кавычки. Внутри них допускается `;`, а кавычка
  записывается как `""`: `"Магазин; ""Сок"""` превращается в `Магазин; "Сок"`.
- Одна операция занимает одну физическую строку; многострочные поля запрещены.
  После закрывающей кавычки разрешены только разделитель или конец строки.
- Пробелы автоматически не удаляются. Пустые описания/счета и строки только
  из обычных пробелов, табуляций, CR/LF запрещены предметными классами.
- Пустая строка внутри файла считается ошибочной операцией. Обычный завершающий
  перенос после последней записи дополнительной ошибкой не считается.

## Ошибки и результат

Неоткрываемый файл, неправильный заголовок и сбой чтения вызывают исключение:
результат импорта не возвращается. Ошибка отдельной строки добавляется в
`ImportResult.errors` с номером строки (заголовок — 1); следующие строки читаются.
Корректные операции доступны в `ImportResult.transactions` в исходном порядке.
Файл только с заголовком даёт пустой успешный результат. Дубликаты пока не удаляются.

При неверных кавычках отклоняется текущая физическая строка; следующая обрабатывается
самостоятельно. Исходный файл не изменяется. Импортёр не назначает категории и не
записывает данные в SQLite: эти действия выполняются отдельно.

## Текущий способ проверки

Импорт подключён к автоматическим тестам, но ещё не к консольному меню.
CTest передаёт тесту абсолютный путь к демонстрационному файлу.
Сквозная проверка импортирует четыре операции, назначает категории трём из них,
а `ИП Иванов` оставляет без категории.
