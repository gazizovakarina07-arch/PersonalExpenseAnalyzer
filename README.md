# PersonalExpenseAnalyzer
проект по ООП

Текущий работающий сценарий: CSV → категоризация по встроенным правилам →
месячный отчёт на русском языке. В консольном меню можно изменять категории,
добавлять и применять правила, повторно строить отчёт. Изменения пока не сохраняются
между запусками.
